Frequently asked

 

Does it really detect ghosts?

PHANTASM measures real electromagnetic fields — the same data professional EMF meters report. What those fluctuations mean is up to you. We make no claim that the readings are evidence of the paranormal; the app is for investigation, exploration, and entertainment.

Why does it say "demo mode" on my iPhone?

Apple does not give web pages access to the raw magnetometer. On iPhone the web app runs a simulated field so you can experience the interface. For true sensor EMF on iOS, the native (Flutter) build is required.

Will switching to Chrome fix it on iPhone?

No. Apple requires every iOS browser — Chrome, Firefox, Edge — to run on Safari's WebKit engine, so they all share the same limits and none can read the raw magnetometer. Switching browsers won't unlock live EMF on iPhone; only the native app will. (On Android, Chrome does expose the sensor, so live readings work there.)

Is my data tracked?

No. There are no ads and no analytics. Everything runs and stays on your device.
